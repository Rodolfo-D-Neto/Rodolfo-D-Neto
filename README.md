# Olá, eu sou o Rodolfo 👋

**Software Engineer focado em EdTech & Automação**

Sou um engenheiro de software especializado em arquitetar soluções tecnológicas que transformam a forma como as pessoas aprendem e interagem com sistemas. Unindo uma base sólida em gestão de tecnologia e pedagogia aplicada a metodologias ativas (STEAM), meu foco é construir produtos completos: desde a modelagem de banco de dados e lógica de backend até a entrega de aplicações interativas e offline-first.

Minha paixão está em resolver problemas complexos do ecossistema educacional e de treinamentos através de código, automação de processos e desenvolvimento de ferramentas que escalam o conhecimento.

## 🚀 O que eu construo e soluciono
*   **Plataformas de Aprendizagem:** Desenvolvimento de sistemas web gamificados com arquitetura de banco de dados própria para gestão de progresso e ensino de lógica de programação.
*   **Automação & Ferramentas Lógicas:** Engenharia de conversores algorítmicos (ex: tradução de programação em blocos visuais para código escrito) e scripts de automação de tarefas.
*   **Soluções Mobile Offline-First:** Construção de aplicativos empacotados (APKs) para ambientes sem conectividade, executando lógicas matemáticas de alta performance no cliente (como sistemas de arbitragem para robótica).
*   **Integração Software-Hardware:** Projetos híbridos envolvendo Python, C/C++ e microcontroladores (Arduino, ESP32) aplicados à IoT e automação física.

## 🛠️ Tech Stack & Ferramentas
*   **Linguagens:** Python (Automação e Backend), JavaScript, SQL (DDL, DML, DQL), C/C++ (Sistemas Embarcados).
*   **Web & Mobile:** HTML5, CSS, ecossistema Capacitor para deploy móvel nativo, arquitetura SPA.
*   **Arquitetura & Processos:** Modelagem de Banco de Dados Relacional, versionamento com Git/GitHub, Clean Code.
